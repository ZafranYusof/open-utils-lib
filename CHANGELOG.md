# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-05-20

### Added
- `clamp()` function for restricting numbers to a range
- `random()` function for generating random integers
- TypeScript type definitions
- GitHub Actions CI workflow

### Changed
- Improved `truncate()` edge case handling for empty strings

## [1.1.0] - 2026-04-15

### Added
- `truncate()` string utility with configurable length
- Unit tests with Jest
- Examples directory

## [1.0.0] - 2026-03-01

### Added
- Initial release
- `capitalize()` string utility
- MIT License
- README with usage documentation
